# Java Architecture Lab

Small, focused projects for exploring Java backend concepts and architectural trade-offs.

- **spring-revision** — Dependency injection, bean configuration, scopes, and lifecycle.
- **spring-boot-revision** — How Spring Boot builds on Spring Framework.
- **pekko-graphql-exploration** — Actor-based state management with Apache Pekko Typed, exposed through GraphQL.

These are learning experiments, not production applications.
